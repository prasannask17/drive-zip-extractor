Privacy Policy – Drive ZIP Extractor

Last updated: October 2026

1. Information We Collect

This application does not collect, store, or transmit any personal data. The app requests read-only access to Google Drive solely to download files that the user explicitly provides via a shared link.

2. How We Use Your Data

We access only the specific Google Drive file provided by the user. Downloaded files are saved locally on the user's machine only. No file contents, metadata, or user information is sent to any external server or third party.

3. Data Storage

No data is stored by this application. All processing happens locally on the user's device. Google OAuth tokens are stored temporarily in memory and discarded when the session ends.

4. Third-Party Sharing

We do not share, sell, or disclose any user data to third parties.

5. Google API Services

This app uses the Google Drive API. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
